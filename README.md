## 🚀 Featured Project

### 🤖 [DevOpsGPT](https://github.com/sayan565/devopsGPT)

> A **multi-tenant, serverless DevOps automation platform**: monitor servers, detect alerts and auto-heal across customer AWS accounts, with an AI assistant and a mobile dashboard.

| | |
|---|---|
| **Team** | 6 members (frontend / backend / DevOps sub-teams) |
| **Architecture** | Multi-tenant SaaS using **AWS STS AssumeRole** for secure cross-account access, with tenant isolation across all tables |
| **Backend** | 7 × AWS Lambda, API Gateway (API key auth), DynamoDB (`GPT_servers`, `GPT_alerts`, `GPT_logs`) |
| **Monitoring & Ops** | EC2 with CloudWatch + SSM agents |
| **AI Layer** | OpenRouter |
| **Frontend** | Flutter mobile dashboard |
